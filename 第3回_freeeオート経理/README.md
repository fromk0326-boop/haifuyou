# 第3回の資料と作業フォルダ

畠山式AI税理士ブートキャンプ **第3回「freeeオート経理（体験版）」**で使う資料と、実行のときに使う作業フォルダです。

**進め方の説明書は、ひとつ上のフォルダ（キットの一番上）の `README.md` です。まずそちらを読んでください。**
このフォルダは「資料置き場＋作業場所」です。

## 中身

| ファイル / フォルダ | 役割 |
|----------|------|
| `勘定科目ルール.md` | 勘定科目ルール表のひな形。freee・マネーフォワードのどちらでも使えます。**AIに読ませる前提**の書き方にしてあり、判定順（NGキーワード → ルール表 → AI判定）も書いてあります |
| `MF会計MCPセットアップガイド.md` | マネーフォワード派の方向け。MF会計の公式MCPサーバーをClaude Codeにつなぐ手順です |
| `requirements.txt` | 体験①②に必要な部品の一覧。`pip install -r 第3回_freeeオート経理/requirements.txt` で使います |
| `請求書PDFを置く場所/` | 体験②で読み取らせる請求書PDFを、ここに置きます |
| `result.csv` | 体験①を実行すると、ここに結果が保存されます（Excelで開けます。最初はありません） |
| `invoice_result.csv` | 体験②を実行すると、ここに結果が保存されます（同上） |

## プログラム本体はどこにあるか

体験①②のプログラム（`auto_keiri.py` / `invoice_ocr.py`）と手順書は、このフォルダではなく `.claude/skills/` の中にあります。

Claude Codeは `.claude/skills/` に置いたものしか「スキル」として認識しないという決まりがあり、ここに移すと「体験①をやりたい」と話しかけても動かなくなるためです。

**読む資料はこのフォルダ、動かすものは `.claude/skills/`** と覚えてください。

| 置き場所 | 中身 |
|----------|------|
| `.claude/skills/setup/` | 準備の手順書＋ `freee_auth.py`（freee認証） |
| `.claude/skills/jido-kicho/` | 体験①の手順書＋ `auto_keiri.py` ＋ `rules.csv`（キーワードの表。Excelで編集できます） |
| `.claude/skills/invoice-ocr/` | 体験②の手順書＋ `invoice_ocr.py` |

## 注意

- `請求書PDFを置く場所/` に入れたPDFと、結果のCSVは、GitHubにアップロードされない設定にしてあります（`.gitignore`）。顧問先の資料が公開される心配はありません。
- 勘定科目・税区分の最終判断は人（税理士・経理担当）が行います。ルール表もAIの判定も「候補」です。
