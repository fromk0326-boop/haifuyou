## キットの入手（最初の一歩）

このキットはGitHubで配布しています。**まず「Fork」で自分のGitHubに複製する**のが受け取りの基本形です（このページ右上の「Fork」ボタン →「Create fork」）。教材が更新されたら、自分のフォークの「Sync fork」ボタンで最新に追いつけます。

> **ブラウザ版Claude Code（claude.ai/code）で使う方**：Forkすればダウンロードは不要です。新しいセッションで自分のフォークを選ぶだけで、教材一式が開いた状態から始められます。

デスクトップ版で使う方は、Forkのあと、次のどちらかで自分のPCに取り込んでください。

### 方法A：クローンで取り込む（推奨。更新も育成もラク）

Claude Codeデスクトップアプリに、次のように頼むだけです。

「私のフォーク https://github.com/（自分のユーザー名）/haifuyou をこのPCにクローンして開いて。gitが無ければインストールから案内して」

クローンで取り込むと、教材の更新は「git pullして」の一言で取り込めて、自分が育てたルール表（`rules.csv`）を自分のGitHubに保存（コミット・プッシュ）することもできます。

### 方法B：ZIPでダウンロード（gitなしでも使える簡易ルート）

1. 自分のフォーク（またはこのページ）の緑の「Code」ボタンを押し、「Download ZIP」を選びます。
2. ダウンロードしたZIPを右クリック →「すべて展開」で、デスクトップなど分かりやすい場所に置きます。

※ この方法は手軽ですが、教材が更新されるたびにZIPの取り直しになります。

> **注意**: フォークしたリポジトリも**インターネットに公開**されます。`.env` や `token.json` などの秘密情報は `.gitignore` で除外済みなので通常は安全ですが、**請求書PDFや自社の情報をフォークにアップロード（コミット）しない**ようご注意ください。

## 共通の準備：Pythonを用意する

第3回の体験①②と、第1回の②セキュリティ・④Hooksで使います。
**第4回のChrome拡張だけを使う方は、この準備は不要です。**

### まず、入っているか確認する

1. スタートメニューで「PowerShell」と検索して開きます（Macの方は「ターミナル」）。
2. 次を入力して、Enterキーを押します。

```
python --version
```

3. `Python 3.12.4` のように、**3.10以上**の数字が表示されればOKです。
   （Macで表示されない場合は `python3 --version` も試してください）

「pythonが見つかりません」と出る場合や、Microsoft Storeの画面が開いてしまう場合は、まだ入っていません。次の手順でインストールします。

### 入っていない場合のインストール手順（Windows）

1. ブラウザで https://www.python.org/downloads/ を開きます。
2. 黄色の「Download Python 3.x.x」ボタンを押して、インストーラーをダウンロードします。
3. ダウンロードしたファイルをダブルクリックして起動します。
4. **最初の画面のいちばん下にある「Add python.exe to PATH」に必ずチェックを入れます。ここがいちばん大事です。**
5. 「Install Now」をクリックして、完了したら「Close」で閉じます。
6. PowerShellを**いったん閉じて、開き直してから**、もう一度 `python --version` を実行します。バージョンが表示されれば成功です。

> 手順の途中で分からなくなったら、Claude Codeに「Pythonをインストールしたい」「インストールしたのに python --version が動かない」など、そのままの言葉で相談してください。画面を見ながら案内してくれます。

## このリポジトリの構成

一番上（ルート）には、**全員が使うもの**だけを置いています。回ごとの資料はフォルダに分けてあります。

| ファイル / フォルダ | 役割 |
|----------|------|
| `README.md` | この案内（キット全体の入口） |
| `CLAUDE.md` | Claude Code用の案内ルール（このフォルダを開くと自動で読み込まれます） |
| `.gitignore` | 秘密情報を誤って公開しないための除外設定。**この場所から動かさないでください**（下記） |
| `.env.example` | 第3回で使う設定ファイルのひな形（コピーして `.env` を作ります） |
| `.env` | 第3回であなたが作る設定ファイル（最初はありません） |
| `.claude/` | **第1回の配布資料**：Claude Codeセットアップ4点セット。**第3回のスキル（`skills/`）もここに同居しています**（下記） |
| `第3回_freeeオート経理/` | **第3回の資料と作業フォルダ** |
| `第4回_Chrome拡張/` | **第4回の配布資料**：Chrome拡張2種 |
| `第5回_帳簿レビュー/` | **第5回の配布資料**：レビュー用プロンプト・観点表・練習用デモ帳簿 |

### なぜ `.gitignore` と `CLAUDE.md` がルートにあるのか

- **`.gitignore`**：この設定は**置かれたフォルダから下にしか効きません**。`.env` と `token.json` はこのキットの一番上に作られるので、`.gitignore` も一番上に無いと、あなたのAPIキーやfreeeのトークンがフォークで公開されてしまいます。**絶対に移動しないでください。**
- **`CLAUDE.md`**：Claude Codeが自動で読み込むのは、開いたフォルダの一番上にある `CLAUDE.md` だけです。移動すると、話しかけるだけで案内してくれる仕組みが動かなくなります。

### `.claude/skills/` について

第3回の体験①②のプログラムと手順書は、`.claude/skills/` の中にあります。
Claude Codeが**この場所しか「スキル」として認識しない**という決まりがあるためです（他の場所に移すと「体験①をやりたい」で発動しなくなります）。

**読む資料は各回のフォルダ、動かすものは `.claude/skills/`** と覚えてください。
