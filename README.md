# freeeオート経理（体験版）

畠山式AI税理士ブートキャンプの配布キットです。このREADMEは**第3回「freeeオート経理（体験版）」**の説明書です。

> このリポジトリには、第1回・第3回・第4回の配布資料が入っています。回ごとにフォルダを分けてあります。
>
> - **第1回**：`.claude/` フォルダ（Claude Codeセットアップ4点セット。そのまま `.claude` として使える形にしてあります。手順は `.claude/README.md` へ）
> - **第3回**：`第3回_freeeオート経理/` フォルダ（このREADMEの体験①②で使う資料・作業フォルダ一式。目次は同フォルダのREADMEへ）
> - **第4回**：`第4回_Chrome拡張/` フォルダ（freee勘定科目ボタン／MF会計アシスト。入れ方は同フォルダのREADMEへ）

freee APIとClaude（AI）を組み合わせて、経理の一部を自動化する流れを体験できます。

このキットでできることは2つです。

- **体験①：自動記帳** freeeの「自動で経理」に溜まった未処理明細を、ルールとAIで仕分けして取引登録する
- **体験②：請求書OCR** 請求書PDFをAIに読み取らせて、内容を一覧化し、freeeに登録する

プログラミングの知識は不要です。表示されるメッセージのとおりに操作すれば動きます。
エラーが出たら、そのエラー文をそのままClaude Codeに貼り付ければ直し方を教えてくれます。

> **おすすめ**: Claude Codeで**このフォルダを開いて**始めてください。
> Claude Codeが自動でこのキットの説明を読み込み、「セットアップして」「体験①をやりたい」と
> 話しかけるだけで、コマンドの実行まで含めて一歩ずつ進めてくれます。
> **以下に出てくるコマンドは、自分で打たなくてもClaude Codeに頼めばOKです。**

## この体験版の「2段階の仕組み」

本物の事務所で動かしている自動経理は、次の2段階でできています。この体験版も**同じ構成**です。

1. **第1段階：手元のルールで判定** `rules.csv`（勘定科目とキーワードの表）で、摘要から勘定科目を当てる。一致すればここで科目が決まります（一瞬で終わり、AI利用料もかかりません）
2. **第2段階：AIが判定** ルールで決められなかった明細だけをClaude（Haiku）に渡し、ふさわしい勘定科目の候補と理由を出させる

そのうえで、**画面に出た結果をあなたが確認し、「これはOK」と選んだものだけ登録**します。
ルールに合っても勝手には登録しません。「判定 → あなたの承認 → 登録」の順に進みます。

> 日々の明細の大半は第1段階で片付き、AIは「ルールにない新顔」だけを受け持ちます。
> `rules.csv` を育てるほど、速く・安く・正確になっていきます。これが本物の運用です。

## 準備（初回だけ）

当日は、この準備を講義で一緒に進めます。事前に読んでおくと当日スムーズです。

### 1. Pythonを用意する（いちばん最初にやること）

このキットはPythonというプログラムで動きます。**Pythonが入っていないと何も始まらない**ので、最初に用意します。

#### まず、入っているか確認する

1. スタートメニューで「PowerShell」と検索して開きます（Macの方は「ターミナル」）。
2. 次を入力して、Enterキーを押します。

```
python --version
```

3. `Python 3.12.4` のように、**3.10以上**の数字が表示されればOKです。準備2へ進んでください。
   （Macで表示されない場合は `python3 --version` も試してください）

「pythonが見つかりません」と出る場合や、Microsoft Storeの画面が開いてしまう場合は、まだ入っていません。次の手順でインストールします。

#### 入っていない場合のインストール手順（Windows）

1. ブラウザで https://www.python.org/downloads/ を開きます。
2. 黄色の「Download Python 3.x.x」ボタンを押して、インストーラーをダウンロードします。
3. ダウンロードしたファイルをダブルクリックして起動します。
4. **最初の画面のいちばん下にある「Add python.exe to PATH」に必ずチェックを入れます。ここがいちばん大事です。**
5. 「Install Now」をクリックして、完了したら「Close」で閉じます。
6. PowerShellを**いったん閉じて、開き直してから**、もう一度 `python --version` を実行します。バージョンが表示されれば成功です。

> 手順の途中で分からなくなったら、Claude Codeに「Pythonをインストールしたい」「インストールしたのに python --version が動かない」など、そのままの言葉で相談してください。画面を見ながら案内してくれます。

### 2. 必要な部品を入れる

このフォルダの中でコマンド画面を開き、次を実行します。

```
pip install -r 第3回_freeeオート経理/requirements.txt
```

これで `requests`（freee通信用）、`anthropic`（Claude用）、`python-dotenv`（設定読み込み用）が入ります。

### 3. 設定ファイル（.env）を作る

このフォルダ直下にあるひな形（`.env.example`）をコピーして、同じ場所に `.env` という名前で保存し、中身を自分の値に書き換えます。

```
copy .env.example .env
```

（Macの方は `cp .env.example .env`）

`.env` に入れる項目は4つです（当日、取得方法を説明します）。

| 項目 | 内容 | どこで取得するか |
|------|------|------------------|
| `ANTHROPIC_API_KEY` | Claudeを使うためのキー | https://console.anthropic.com/ の API Keys |
| `FREEE_CLIENT_ID` | freeeアプリのID | freeeアプリ管理画面 |
| `FREEE_CLIENT_SECRET` | freeeアプリの秘密鍵 | freeeアプリ管理画面 |
| `FREEE_COMPANY_ID` | 対象の事業所ID | freeeのURLの `company_id=` の数字 |

> `.env` は秘密情報です。人に共有したり、GitHubに上げたりしないでください（`.gitignore`で除外済みです）。

### 4. freeeアプリの「コールバックURL」を登録する

freeeアプリの管理画面で、コールバックURL（リダイレクトURI）に次の値を**完全一致**で登録してください。

```
http://127.0.0.1:8088/callback
```

1文字でも違うと、次の認証でエラーになります。

### 5. freeeにログインして認証する（token.jsonを作る）

次を実行すると、ブラウザが開きます。freeeにログインして「許可する」を押してください。

```
python .claude/skills/setup/freee_auth.py
```

成功すると、このフォルダの直下に `token.json` が作られ、以降はこのファイルを自動で使います。

> 事業所ID（`FREEE_COMPANY_ID`）がわからない場合は、認証後に次を実行すると一覧が出ます。
> ```
> python .claude/skills/setup/freee_auth.py --companies
> ```

## 体験①：自動記帳を動かす

### まずは「見るだけ」（登録しないので安全です）

```
python .claude/skills/jido-kicho/auto_keiri.py
```

- freeeの未処理の**出金明細**を最大5件取ってきます。
- 各明細を2段階（ルール判定 → ルール外だけAI判定）で仕分けし、結果を一覧表示します。
- 同じ内容を `第3回_freeeオート経理/result.csv`（Excelで開けます）にも保存します。
- 件数を変えたいときは `--limit` を付けます（例：3件だけ）。
  ```
  python .claude/skills/jido-kicho/auto_keiri.py --limit 3
  ```

一覧では、各明細の先頭に「明細ID」が付き、判定が次のどれかになります。

| 判定 | 意味 |
|------|------|
| 登録候補 | ルール表に一致した、またはAIが科目を判定できた明細。承認すれば登録できる |
| 要確認 | AIの確信度が低い、または科目が決められない。人が見るべき明細 |
| 要確認（スキップ） | 給与・借入・税金や、請求書の決済っぽい明細。自動登録しない |

一覧には「判定元」も表示されます。**ルール**＝rules.csvで決まった明細、**AI**＝Claudeが判定した明細です。

### 確認して「OK」なものだけ登録する

一覧を見て、登録してよいと判断した明細の「明細ID」を指定して実行します。

```
python .claude/skills/jido-kicho/auto_keiri.py --register --ids 123,456
```

指定したIDのうち「登録候補」のものだけ、freeeに取引登録されます。

`第3回_freeeオート経理/請求書PDFを置く場所/` に、読み取らせたい請求書PDFを置きます（何枚でもOK）。

```

```

各PDFについて、取引先名・請求日・支払期日・税込金額・内容の要約・勘定科目の候補・源泉所得税の対象らしさを一覧表示し、`第3回_freeeオート経理/invoice_result.csv` にも保存します。

内容（特に金額と日付）を確認したうえで、登録したい請求書を指定します。

```

```

## 安全のための決めごと（必ず読んでください）

このキットは「体験用」です。事故を防ぐため、次の制限をかけています。

- **少額・少件数から**：出金明細は一度に最大5件までしか取りません。まずは金額の小さい明細で試してください。
- **承認してから登録**：ルールやAIが判定しても、勝手には登録しません。あなたが選んだ明細だけを登録します。
- **給与・税金・借入は登録しない**：これらは「要確認（スキップ）」に回します。
- **消込はしません（重要）**：freeeには明細を自動で「消し込む」APIがありません。そのため、このキットで取引を登録しても、freeeの「自動で経理」画面には**元の明細が未処理のまま残ります**。
  登録後は、freeeの画面で該当明細を**「無視」にする**か、**手動で今登録した取引に紐づけて**ください。放置すると、同じ取引を二重に計上する原因になります。

- エラー文が出たら、**その文をそのままClaude Codeに貼り付けて**「これを直したい」と聞いてください。原因と直し方を教えてくれます。
- `FREEE_... が未設定です` と出たら、`.env` の中身を見直してください。
- 認証でエラーが出たら、freeeアプリのコールバックURLが `http://127.0.0.1:8088/callback` と完全一致しているか確認してください。
- 日本語が文字化けする場合も、まずはエラー画面ごとClaude Codeに相談してください。
