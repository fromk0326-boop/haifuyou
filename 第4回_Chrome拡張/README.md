# 第4回の配布物：Chrome拡張

畠山式AI税理士ブートキャンプ **第4回**で配布した Chrome拡張です。
マネーフォワード クラウド会計の入力画面に、勘定科目のボタンパネルなどを重ねて表示し、キーボード入力を減らします。

| フォルダ | 対応ソフト | できること |
|----------|-----------|-----------|
| `mf-bulk-select-extension/` | マネーフォワード クラウド会計 | ルール一致明細の一括チェック＋勘定科目ボタンパネル |

「🔍 何費？検索」（勘定科目辞典を小窓で開く機能）を備えています。

> **freee会計をお使いの方へ**：「freee勘定科目ボタン」は現在も機能追加が続いているため、キットのルート直下 `追加配布/freee-kamoku-buttons/` に移動しました。入れ方は `追加配布/freee-kamoku-buttons/README.md` を読んでください。

## 入れ方

1. Chromeで `chrome://extensions` を開く（Braveは `brave://extensions`）
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `mf-bulk-select-extension` フォルダを選ぶ

**細かい手順と使い方は、`mf-bulk-select-extension/README.md` を読んでください。**
うまく入らないときは、画面のスクリーンショットをClaude Codeに貼って相談すれば案内してくれます。

> フォルダ名が英語のままなのは、Chromeに読み込ませるときに日本語のフォルダ名がトラブルの原因になることがあるためです。変更しないでください。

## 注意

- この拡張は**入力を助けるだけ**で、勘定科目を自動で判断するものではありません。何を選ぶかは今までどおりご自身で決めてください。
- 拡張は各ソフトの画面構成に合わせて作ってあります。ソフト側の画面が変わると動かなくなることがあります。その場合は講義でお知らせします。
