# プロンプト②：消費税区分レビュー（6観点）

課題ページ ステップ④で使うプロンプトです。プロンプト①と同じく2種類あります。

- **A. 自分の事業所版**：freee／MF会計につないでレビューします
- **B. デモ帳簿版**：`デモ帳簿_株式会社デモテック.xlsx` でレビューします

---

## A. 自分の事業所版（freee MCP）

```
freee MCPを使います。最初に、いま接続されている事業所名を確認して見せてください。
あわせて、この事業所の税込・税抜の設定と、消費税の課税方式（原則・簡易・2割特例など）が
分かれば教えてください。私が「OK」と言ってから、次に進んでください。

OKと言ったら、直近3ヶ月（私が別の期間を指定したらその期間）の取引を取得して、
消費税区分を次の6観点で点検してください。

1. 税込1万円未満の課税仕入で、インボイスなし（80%控除）の区分のままのもの
   （少額特例を使えば全額控除にできる可能性がある。ただし適用要件の判断は私がする）
2. 海外SaaS（Claude、ChatGPT、Zoom、Canvaなど）の支払が
   国内の課税仕入として処理されていないか
3. 軽減税率8%が飲食料品・定期購読新聞以外に付いていないか
4. 登録番号のない相手（免税事業者と思われる相手）への支払が
   適格（100%控除）で処理されていないか
5. 非課税（土地賃料・保険料・利息など）と対象外（海外取引・給付金など）が
   混同されていないか
6. 売上側の区分は正しいか（課税売上10%か、値引き・返金の処理が適切か）

結果は「観点／該当取引（日付・摘要・金額・いまの税区分）／
提案する税区分／理由」の表にして、税区分レビュー_YYYYMM.md に保存してください。

大事なルール：
- 一括修正はしないでください。私が内容を確認して「この取引を直して」と
  指定したものだけ、1件ずつ修正してください
- 適用要件の判断（少額特例が使えるか等）や、迷う論点は
  「確認事項」として私に残してください。税務判断はあなたの仕事ではありません
```

**MF会計の方**：1行目を「MF会計のMCPを使います」に変えて、税区分は**freeeのコード番号ではなく名称**（課税仕入10%・軽減8%・非課税・対象外など）で指示してください。観点は同じです。

## B. デモ帳簿版（Excelを読ませる）

```
このフォルダにある「第5回_帳簿レビュー/デモ帳簿_株式会社デモテック.xlsx」の
仕訳帳シートを読んでください。税区分・税率の列があります。

読めたら、消費税区分を次の6観点で点検してください。
対象期間は帳簿の全期間です。この会社は税抜経理・原則課税・
インボイス発行事業者という前提にしてください。

1. 税込1万円未満の課税仕入で、インボイスなし（控80）の区分のままのもの
   （少額特例を使えば全額控除にできる可能性がある。ただし適用要件の判断は人がする）
2. 海外SaaS（Claude、ChatGPT、Zoom、Canvaなど）の支払が
   国内の課税仕入として処理されていないか
3. 軽減税率8%が飲食料品・定期購読新聞以外に付いていないか
4. 登録番号のない相手（免税事業者と思われる相手）への支払が
   適格（100%控除）で処理されていないか
5. 非課税（土地賃料・保険料・利息など）と対象外（海外取引・給付金など)が
   混同されていないか
6. 売上側の区分は正しいか（課税売上10%か、値引き・返金の処理が適切か）

結果は「観点／該当取引（日付・摘要・金額・いまの税区分）／
提案する税区分／理由」の表にして、デモ税区分レビュー.md に保存してください。

大事なルール：
- 登録番号の有無など、帳簿の外の事実は確認できません。
  「相手の登録状況を確認する」のような確認事項として残してください
- 適用要件の判断や迷う論点は「確認事項」に残してください。
  税務判断はあなたの仕事ではありません
```

こちらも `デモ帳簿の答え合わせ.md` で答え合わせできます。

> **ご注意**：自分の事業所版のレビュー結果には取引先名や金額が入ります。
> GitHubのフォークにアップロードしたり、掲示板に貼ったりしないでください。
> 税区分の修正は消費税申告の数字に直結します。体験はテスト用か自分の事業所で行い、
> 本番データを直すときは必ず修正前後の一覧を残してください。
